# 随身音乐遥控器

首次使用需要 Windows 电脑、可用蓝牙、桌面版网易云音乐，以及配套电脑桥接程序。音乐在电脑播放；设备无需配网。已验证网易云版本为 3.1.31.205174，其他版本或更新后可能需要适配。

1. 先从 https://github.com/wyh1351/passport-music/releases/latest 下载 PassportMusic-Windows-v1.0.2.zip，解压到长期保留的文件夹。保留 PassportMusic.exe、PassportMusicBackground.exe 和 _internal 文件夹。
2. 使用社区刷机工具刷入本玩法的完整固件。完整固件从 0x0 写入，可能清除原设备设置和蓝牙配对；不要把应用升级镜像写到 0x0。首次刷入后设备显示等待电脑连接。
3. 双击 Enable-Autostart.cmd，允许桥接在登录 Windows 后后台运行。它不会自动打开网易云。首次先完全退出网易云，包括托盘实例，再运行 Open-NetEase-Remote.cmd；它会用遥控参数打开原版网易云。选择一首可播放歌曲。
4. 在 Windows“设置 → 蓝牙和设备 → 添加设备 → 蓝牙”中选择 Passport Music，输入设备屏幕上的六位码。连接后设备显示歌名、三行歌词和进度；已绑定设备会自动重连。请不要同时运行多个桥接。
5. 日后也可直接从网易云桌面/任务栏快捷方式打开，但快捷方式的目标末尾须有 --remote-debugging-port=9223 --remote-debugging-address=127.0.0.1。补参数后必须完全退出旧的网易云实例再重开。客户端更新或重新固定图标后可能要重新补参数。

主页操作：上/下短按调节网易云内部音量 ±5 个百分点，双击 ±20，长按上一首/下一首。确定短按播放/暂停，双击开启或关闭电脑桌面歌词，长按进入设置。

设置：上/下选“歌词微调、自动息屏、屏幕亮度”，短按确定进入。详情页短按确定返回菜单，任意设置页长按确定回主页。歌词微调短按每次 50ms、长按 250ms，正值更早、负值更晚；范围 ±2000ms。息屏可选 15秒、30秒、1/2/5/10分钟或永不；亮度 5%～100%。停止调节约一秒后自动保存。息屏后先按任意键唤醒，唤醒这次按键不执行音乐操作。

Windows 歌词优先通过 IPv4 直连，直连失败才尝试最新代理设置；已在作者当前网络实测退出 FlClash 后切歌，设备歌词显示与换句正常。网络或歌词服务异常时仍可能失败。无歌词时可在桥接旁的 lyrics 文件夹放入 UTF-8、带时间标签的“歌名 - 歌手.lrc”，再重启桥接；文件名中的 Windows 非法字符替换为下划线。桥接不读取账号 Cookie。

排障：进度或应用音量不可用时，先检查网易云启动参数并完全退出后重开。查看 Background-Status.cmd；Stop-Background.cmd 只停止后台，Disable-Autostart.cmd 关闭自启。蓝牙配对失败先按 Windows 提示重新配对。电脑或网络暂时不可用时后台会重试。

电量显示说明：作者这一台设备在长时间插电、指示灯熄灭后曾显示原始 98%，因此本包 v14 固件保留针对该单台设备的显示校准：原始 98% 映射为屏幕 100%，其余有效读数按比例显示。这不是所有 AI Passport 的共同问题，也不是通用充电修复；不能由作者的个例推断其他设备故障。其他设备使用此固件可能出现电量显示偏差。该映射不改变充电控制，也不表示实测电池容量达到 100%。如需保留原始百分比，可在源码 main/music_battery.h 中将 MUSIC_BATTERY_FULL_SOC 从 98 改为 100 后重新构建；本次字库更新保留该显示映射。封面为玩法示意图。发布的完整 0x0 镜像已通过构建校验；实际功能在保留设置的应用升级路径上验收，完整 0x0 实刷、真实重新登录启动及长期续航仍未验证。

已安装旧版桥接时：先运行原目录 Stop-Background.cmd，等后台退出并备份安装目录，将新版 PassportMusic 文件夹内的文件覆盖到原目录，保留 lyrics 文件夹，再运行 PassportMusicBackground.exe --background。无需重复开启自启；已有兼容版本用户可用本包应用镜像在0x10000保留设置升级；同时更新电脑桥接。

歌曲文字显示：本版支持原中文/西文、日文平假名与片假名、全部现代韩文音节及常用韩文字母。配套新版桥接会合并可组合的假名浊音和韩文字符。菜单仍为中文；未收录的其他文字、表情或罕见汉字仍可能显示问号，不承诺全部语言或复杂文字排版。作者设备已实测日文/韩文显示通过。
