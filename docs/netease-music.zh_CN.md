# 随身音乐遥控器

准备：Windows 10/11 电脑、蓝牙、桌面版网易云音乐。设备不用配网，在线歌词需要电脑联网。

第一次使用
1. 用社区刷机工具刷入本玩法固件，保持设备开机。
2. 下载 [Windows 电脑控制器 v1.3.1](https://github.com/wyh1351/passport-music/releases/download/v1.3.1/PassportMusic-Windows-v1.3.1.zip)，解压到一个文件夹。不要只移动单个程序，保留配套文件夹。
3. 双击 PassportMusicControl.exe，在主界面点击“开始使用”。软件会安装后台、创建桌面“Passport Music”快捷方式，并启用登录后自动运行。
4. 点击“打开网易云”并播放歌曲。网易云已运行时会显示原窗口，包括收进托盘的情况；若需要重启来启用遥控，会先提醒。
5. 点击“蓝牙设置”，添加 Passport Music，输入设备屏幕上的六位码。配对只需首次完成；连接后，设备显示歌名、歌词和进度。

以后怎么用
直接打开已配置好的网易云即可，电脑控制器会在后台运行。点击桌面“Passport Music”或托盘图标打开状态页，右键托盘可打开网易云、重新连接设备、进入设置或退出。
关闭控制器窗口只收回托盘；“退出”会停止本次连接，下次登录仍按自启设置运行。不要同时启动多份旧版桥接。

主页按键
- 上键：短按音量 +5，双击 +20，长按上一首。
- 下键：短按音量 -5，双击 -20，长按下一首。
- 确定：短按播放／暂停，双击开关电脑桌面歌词，长按进入设备设置。
音量调的是网易云自己的滑块，数字指百分点。息屏后按任意键先唤醒，这次按键不执行音乐操作。

设备设置
上／下选择，短按确定进入或从详情页返回，长按确定随时回歌词主页。
- 一级菜单：歌词微调、屏幕设置、外观设置、返回。“返回”回歌词主页。
- 屏幕设置：屏幕亮度、自动息屏、返回。“返回”回上一级。
- 外观设置：界面背景、屏幕宠物、返回。“返回”回上一级。
歌词微调：上键更早、下键更晚；短按 50ms、长按 250ms，范围 ±2000ms。
亮度：5%～100%，短按调整 5、长按调整 20 个百分点。
自动息屏：15秒、30秒、1／2／5／10分钟或永不息屏。
背景：默认白底和九款像素图，上／下切换，显示名称和序号，播放与设置页使用同一背景。
宠物：耳机猫、小狗、小兔、企鹅或不显示。主页和设置中都跟随播放／暂停。
停止调节约一秒后自动保存，重启保留；设置页底部不添加提示。

电脑设置
“登录 Windows 后自动运行”可开关登录自启与后台异常恢复，取消勾选不会中断当前连接。未安装时，“未安装后台”为灰色状态，首次安装从主页“开始使用”进入；已安装时可点击“重新安装后台”修复后台。
“诊断日志”打开日志文件夹；“查看更新”打开下载页。歌词自动在线获取，界面无需配置本地歌词。
重新安装时，按钮显示进行状态并暂时禁用；完成后弹窗确认后台已启动，失败时显示具体原因。窗口首次在当前显示器居中打开，以后记住位置和大小；更换显示器后会保持窗口可见。

旧用户升级
解压新电脑包，打开其中的 PassportMusicControl.exe，点击“开始使用”更新原安装；也可运行包内 Enable-Autostart.cmd。原端口配置、自启、配对和已有文件保留，安装后从桌面快捷方式打开。
要使用新设备菜单，兼容现有分区时仅将 PassportMusic-v23-app.bin 写到 0x10000，不全片擦除，保留设置和配对。完整 FoloToy-AI-Passport-full.bin 用于从 0x0 刷写，可能重置设置和配对；应用文件不能写到 0x0。不确定时使用社区完整刷写并重新配对。

遇到问题
- 设备未连接：保持设备开机、电脑蓝牙开启；首次先完成配对，之后软件自动重试，也可点击“重新连接设备”。
- 音量或进度不可用：在控制器中重新打开网易云；需要重启时按提示操作。
- 歌词查询失败：检查电脑网络，软件会自动重试，也可切一首歌确认；部分歌曲可能没有可用在线歌词。
- 控制端口被占用或被 Windows 保留：默认仍是 9223，与 FlClash 代理端口无关。在“设置”中选择一个可用端口并保存，然后重新打开网易云。使用原桌面／任务栏图标时，还要将快捷方式参数改成相同端口；可用“复制启动参数”。正常用户不必修改。
- 从原网易云快捷方式打开：目标末尾保留 --remote-debugging-port=9223 --remote-debugging-address=127.0.0.1（使用自定义端口时替换 9223），放在程序路径引号外。网易云更新或重新固定图标后可能需要补回参数。

已验证网易云 3.1.31.205174；其他或后续版本可能需要适配。菜单为中文，支持中文／西文、日文假名和现代韩文，其他文字或表情可能不显示。公开固件显示原始电量，不含个人校准；电脑包默认 9223，不带个人端口配置。配图中的歌曲为演示内容，电脑界面为本机截图。
